Changelog

All notable changes to this project will be documented in this file.

Versioning follows a pragmatic model rather than strict semantic versioning.

---

## [1.0.0] - 2026-04-28

### Added
- Initial public release of the Freshservice API Client
- Robust HTTP session management with retries and timeouts
- Pagination helpers for list-based endpoints
- Core ticket lifecycle APIs (create, read, update, bulk update)
- Filtering and search support
- Attachment download handling
- Optional Pydantic models for tickets, conversations, and requesters
- Context-manager support for safe session cleanup

### Notes
- Although tagged as 1.0.0, the API surface may continue to evolve
- Backwards-compatible changes are preferred but not yet guaranteed
